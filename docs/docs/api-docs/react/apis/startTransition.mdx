`React.startTransition` marks the state updates inside it as a non-blocking transition, like the function returned by [`useTransition`](../hooks/useTransition.mdx). It can be called anywhere, including outside of components (e.g. in a store), but it doesn't give you an `isPending` flag.

```fsharp
React.startTransition (fun () -> setQuery value)
```

It also accepts an async action. State updates after a `let!` need their own `startTransition`:

```fsharp
React.startTransition (fun () -> promise {
    let! data = loadData ()
    React.startTransition (fun () -> setData data)
})
```

In the example below, the input updates on every keystroke, while the slow list is updated in a transition.
