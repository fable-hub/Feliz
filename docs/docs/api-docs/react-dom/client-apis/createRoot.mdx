`ReactDOM.createRoot` is used to initialize a React root and render your application into a DOM element. This is the recommended way to start a React app in modern React.

## Root options

Pass `RootOptions` as the second argument to hook into React's error handling, or to prefix the IDs generated by `React.useId`:

| Option | Meaning |
| --- | --- |
| `onCaughtError` | Called when an [error boundary](../../react/components/ErrorBoundary.mdx) catches an error. |
| `onUncaughtError` | Called when an error is not caught by any error boundary. React unmounts the app in that case. |
| `onRecoverableError` | Called when React recovers from an error by itself, e.g. a hydration mismatch. |
| `identifierPrefix` | Prefix for `useId`. Avoids ID conflicts when several React roots share a page. |

The error callbacks receive the error and a `ReactErrorInfo` with the component stack. They are a good place to report errors to a logging service.
