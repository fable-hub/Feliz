`ReactDOM.hydrateRoot` is used to hydrate server-rendered HTML with React, attaching event handlers and making the UI interactive. This is essential for server-side rendering (SSR) setups.


import RawHydrateRoot from '!!raw-loader!../../../feliz-docs/Examples/ReactDOM/HydrateRoot.fs'
import CodeBlock from '@theme/CodeBlock';

<CodeBlock language="fsharp" >
{RawHydrateRoot}
</CodeBlock>

`hydrateRoot` accepts the same `RootOptions` as [`createRoot`](./createRoot.mdx#root-options) as a third argument. If you set `identifierPrefix`, it must match the prefix used on the server. Hydration mismatches that React can recover from are reported to `onRecoverableError`.

```fsharp
ReactDOM.hydrateRoot (
    document.getElementById "root",
    App(),
    RootOptions(onRecoverableError = fun error _ -> console.warn ("Hydration issue:", error.Message))
)
```
